# Tour Price Builder

ระบบคำนวณราคาและวางแผนโปรแกรมทัวร์ — ไฟล์ HTML ไฟล์เดียว ไม่ต้องติดตั้งอะไร ทำงานออฟไลน์ได้

## ⚠️ กฎข้อเดียวที่ห้ามลืม

**`index.html` ในโฟลเดอร์นี้เป็นเว็บสาธารณะ** — GitHub Pages ของบัญชี Free และ Pro เปิดให้ทุกคนเข้าถึงเสมอ
ต่อให้ตั้ง repo เป็น private ก็ตาม (Pages แบบปิดมีเฉพาะ Enterprise)

ดังนั้น **ห้ามมีข้อมูลจริงอยู่ใน `index.html`** ไม่ว่ากรณีใด:

| ห้ามขึ้นเว็บ | เพราะ |
|---|---|
| ราคาต้นทุนสถานที่ / ร้านอาหาร | คู่แข่งเห็นมาร์จิ้นทั้งหมด |
| ชื่อ-นามสกุลและเบอร์ไกด์ | ข้อมูลส่วนบุคคลของคนอื่น · มีประเด็น PDPA |
| ลิงก์ Google Sheet | ชี้ตรงไปที่ข้อมูลสดทั้งหมด |

ข้อมูลจริงอยู่ที่ **Google Sheet** เท่านั้น แอปดึงมาตอนใช้งานแล้วเก็บไว้ในเครื่อง

## โครงสร้าง

ไฟล์ตัวจริงอยู่**นอก repo** ตั้งใจให้เป็นแบบนั้น เพื่อไม่ให้ข้อมูลจริงมาอยู่ใกล้สิ่งที่ push ขึ้น GitHub

```
%USERPROFILE%\Downloads\
  tour_pricing_app_v25.html   ← ตัวจริงที่ใช้ทำงานและเปิดใช้เอง (มีข้อมูลจริง · ห้ามขึ้นเว็บ)

tour-planner\                 ← repo นี้
  index.html                  ← ตัวโปรแกรมเปล่า · สร้างจาก build.ps1 เท่านั้น · ขึ้นเว็บ
  build.ps1                   ← ถอดข้อมูลจริงออก + ตรวจซ้ำก่อนปล่อย
  .githooks\pre-commit        ← บล็อกอีกชั้นถ้าข้อมูลจริงเล็ดลอดมา
```

## กติกาเรื่องเวอร์ชัน

**เหลือไฟล์เวอร์ชันเดียวเสมอ** แก้แล้วให้สร้างเลขเวอร์ชันใหม่ แล้วลบตัวเก่าทิ้งทันที
เพราะไฟล์นี้ถูกเปิดใช้จากเครื่องโดยตรง มีหลายเวอร์ชันในโฟลเดอร์เดียวกันแล้วเปิดผิดตัวง่ายมาก

`build.ps1` จะหยิบไฟล์ `tour_pricing_app_v*.html` ที่เลขสูงสุดมาใช้เอง ไม่ต้องแก้พาธเวลาขึ้นเวอร์ชัน
และจะ**เตือนให้เห็นชัดถ้ายังมีเวอร์ชันเก่าค้างอยู่**

## วิธีแก้แล้วอัปเดตเว็บ

แก้ที่ไฟล์ตัวจริงใน `Downloads` แล้วสั่ง build:

```powershell
powershell -ExecutionPolicy Bypass -File .\build.ps1
```

Windows ตั้งค่าเริ่มต้นมาบล็อกการรันไฟล์ `.ps1` จึงต้องใส่ `-ExecutionPolicy Bypass`
(ถ้าเครื่องอนุญาตอยู่แล้ว พิมพ์ `.\build.ps1` เฉย ๆ ก็ได้)

ระบุไฟล์ต้นทางเองก็ได้:

```powershell
powershell -ExecutionPolicy Bypass -File .\build.ps1 -Source "D:\ที่อื่น\ไฟล์.html"
```

## ชุดทดสอบ

รันด้วย headless Chrome ไม่ต้องลง Node อะไรเลย

```powershell
powershell -ExecutionPolicy Bypass -File .\tests\run.ps1
```

| คำสั่งเพิ่มเติม | ทำอะไร |
|---|---|
| `-Shipped` | ทดสอบ `index.html` (ไฟล์ที่ deploy) แทนไฟล์ตัวจริง |
| `-Filter timeline` | รันเฉพาะไฟล์ที่ชื่อมีคำนั้น |
| `-Source "path"` | ชี้ไฟล์เอง |
| `-Keep` | เก็บหน้าทดสอบที่ประกอบไว้ ไว้เปิดดูเองในเบราว์เซอร์ |

คืน exit code 0 เมื่อผ่านหมด และ 1 เมื่อมีตก — **git hook เรียกใช้ตัวนี้ก่อน commit ทุกครั้งที่ `index.html` ถูกแก้** ถ้าเทสต์ตก commit จะไม่ผ่าน

| ไฟล์ | ครอบอะไร |
|---|---|
| `01-time` | อ่านค่าเวลาทุกรูปแบบ ไทย/อังกฤษ/นาฬิกา/ช่วง + วันหยุด |
| `02-columns` | จับคู่คอลัมน์จากหัวตาราง + โครงคอลัมน์ยาวเท่ากันทุกทาง |
| `03-routes` | เวลาเดินทางแบบมีลำดับชั้น + ทะเบียนพื้นที่ |
| `04-tiers` | ราคาตามช่วง PAX + การล็อกราคาที่แก้เอง |
| `05-timeline` | ลำดับเวลารายวัน + คำเตือน + หมุดโรงแรม |
| `06-output` | ทั้ง 4 ช่องทางต้องให้โปรแกรมตรงกัน |
| `07-smoke` | ของเดิมไม่พัง · ผ่านทั้งไฟล์ที่มีข้อมูลและไฟล์เปล่า |
| `08-guides` | ไกด์เก็บเป็นจำนวนตามประเภท · ไม่มีข้อมูลส่วนบุคคลหลงเหลือ |

**หมายเหตุเรื่องการเขียนเทสต์:** แอปประกาศ `S` `parseDur` `recalc` ด้วย `let`/`const`
ค่าพวกนี้จึงไม่ติดอยู่บน `window` เข้าถึงจากนอกหน้าไม่ได้
ตัวรันจึงฉีดไฟล์เทสต์เข้าไปเป็น `<script>` ต่อท้ายในหน้าแอปเอง เทสต์จะได้อยู่ในสโคปเดียวกับโค้ดจริง

## ถ้าไฟล์ตัวจริงหาย จะกู้คืนได้ไหม

ได้ เพราะมันประกอบขึ้นจากสองส่วนที่ถูกเก็บแยกกันไว้แล้ว:

| ส่วน | เก็บอยู่ที่ | กู้อย่างไร |
|---|---|---|
| โค้ดทั้งหมด | git ของ repo นี้ (`index.html`) | `git checkout` เวอร์ชันที่ต้องการ |
| ข้อมูลจริง | Google Sheet | เปิดแอปแล้วกด **⬇️ ดึงจากชีต** |

`build.ps1` แก้แค่สองจุด (ก้อน `const DB` และค่าเริ่มต้นของ `gsUrl`) ที่เหลือเหมือนกันทุกตัวอักษร
ดังนั้น `index.html` + ข้อมูลจากชีต = ไฟล์ตัวจริง

**เงื่อนไขเดียว:** ต้องกด **⬆️ ส่งขึ้นชีต** ให้ข้อมูลในชีตเป็นตัวล่าสุดอยู่เสมอ ไม่งั้นครึ่งที่เป็นข้อมูลจะกู้ไม่ครบ

## เวอร์ชันเก่าที่เก็บไว้เป็น tag

เวอร์ชันเก่าถูกลบออกจากโฟลเดอร์ตามกติกา แต่โค้ดยังอยู่ใน git เป็น tag
เก็บแบบไม่ทิ้งไฟล์ค้างในโฟลเดอร์ ต้องสั่งดึงเองเมื่อจะใช้

```bash
git tag -l                                        # ดูว่ามี tag อะไร
git show v22-archive:index.html > v22.html        # ดึงเวอร์ชันนั้นออกมา
```

| tag | คือ |
|---|---|
| `v22-archive` | ก่อนมี P0/P1 — จุดถอยกลับถ้า P0/P1 มีปัญหาในการใช้จริง |
| `v23` | tier pricing · สำรองอัตโนมัติ · อ่านเวลาทุกรูปแบบ · โมดัลกลางจอ |
| `v24` | ไทม์ไลน์รายวัน · Output ทุกช่องทางใส่เวลาได้ |
| `v25` | เลิกเก็บชื่อและเบอร์ไกด์ · เปลี่ยนเป็นจำนวนตามประเภท |

ไฟล์ที่ดึงออกมาเป็นตัวโปรแกรมเปล่า เปิดแล้วกด **⬇️ ดึงจากชีต** เพื่อเอาข้อมูลกลับมา

แล้ว commit ตามปกติ — `build.ps1` จะ**ลบ `index.html` ทิ้งเองถ้าตรวจเจอข้อมูลจริงหลุดมา** และมี git hook คอยบล็อกอีกชั้นหนึ่ง

## การตั้งค่าครั้งแรกหลังเปิดเว็บ

เปิดเว็บครั้งแรกจะยังไม่มีข้อมูลเลย ทำครั้งเดียวจบ:

1. กด **🗄 ฐานข้อมูล**
2. วางลิงก์ **Google Sheet** และลิงก์ **Web App (`/exec`)**
3. กด **⬇️ ดึงจากชีต**

ข้อมูลจะถูกเก็บไว้ในเบราว์เซอร์เครื่องนั้น ครั้งต่อไปเปิดมาใช้ได้เลยแม้ไม่มีเน็ต

## ทำไมต้องขึ้นเว็บ ไม่เปิดไฟล์จากเครื่อง

เปิดจากไฟล์ (`file://`) Google จะไม่ส่งหัว CORS กลับมา แอปเลยส่งข้อมูลขึ้นชีตตรง ๆ ไม่ได้ ต้องใช้ทางอ้อมซึ่งช้ากว่าและพลาดง่ายกว่า
พออยู่บน `https://` การซิงก์และการสำรองอัตโนมัติจะยิงตรงและรู้ผลทันที
